🛒 Lista de Compras

Uma aplicação simples e prática para organizar itens de compras diretamente pelo navegador.

O projeto permite adicionar produtos à lista, marcar itens como concluídos e remover o que não for mais necessário, deixando as compras mais organizadas e fáceis de acompanhar.

✨ Funcionalidades

Adicionar novos itens à lista

Marcar produtos como comprados

Remover itens da lista

Interface simples e responsiva

Organização prática para o dia a dia

🛠️ Tecnologias utilizadas

HTML5

CSS3

JavaScript

📁 Estrutura do projeto

listadecompras/
├── index.html
├── style.css
├── script.js

🚀 Como executar o projeto

Clone este repositório:

git clone https://github.com/CarineLimma/listadecompras.git

Entre na pasta do projeto:

cd listadecompras

Abra o arquivo index.html no navegador.

Também é possível utilizar a extensão Live Server no VS Code.

💡 Objetivo do projeto

Este projeto foi desenvolvido para praticar conceitos de desenvolvimento front-end, manipulação do DOM, eventos em JavaScript e criação de interfaces responsivas.
